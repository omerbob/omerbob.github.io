Points can go up to 100,000; large 3D samples can take a while for the persistence functionals, and each sample computes in the background. Homology is computed only up to radius 5 × the largest nearest-neighbour distance in the sample; features still alive there are left out (the plot header shows how many were cut). Normalize (log-log scale only) plots z = (log log x − μ) / σ, with the mean μ and standard deviation σ of log log x taken separately for each sample (signal loops excluded). PDF shows a kernel density estimate of the variable on the x-axis as drawn (e.g. of log log x on the log-log scale); for degrees it shows the PMF. Overlay merges the three ECDFs into one plot; Split separates them again. For H₁, the x-axis range ignores the signal cycles of the annulus (1) and the torus (2) (their values still count in the ECDF). Hover a plot to read F(x). Log-log puts log(log x) on the x-axis, so it is offered only when every value is above 1; log needs every value above 0. All four functionals are scale-free, so the distributions offer only shape parameters. The sphere and torus are listed under 2D because they are 2-dimensional surfaces; they are sampled and drawn in 3D space.
